# Workspace Guidelines
- Tüm `src/` klasörü altındaki kaynak kodlarda, bir dosyanın boyutunun 1500 satırı geçmemelidir
- Hiçbir kod ve metinde firma isimleri geçmemelidir
- "as any" kullanmak yasaktır
- hardcoded color olmamalıdır
- her prompt sonrası "npm run check" gibi komutlar yapma, ben yaparım
